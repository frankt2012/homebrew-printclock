# Homebrew Tap for PrintClock

Homebrew cask for [PrintClock](https://github.com/frankt2012/PrintClock), a
native macOS app that tells you exactly when a 3D print will finish.

```sh
brew tap frankt2012/printclock
brew trust frankt2012/printclock
brew install --cask printclock
```

Homebrew asks you to trust third-party taps once before installing.

To update:

```sh
brew upgrade --cask printclock
```
